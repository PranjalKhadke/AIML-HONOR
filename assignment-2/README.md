File-based CRUD system implementing persistent employee data management using Python's standard `csv` library.

### Features
- Complete CRUD operations: Create, Read/Display, Update (name/department/salary), Delete.
- Primary key enforcement (prevents duplicate employee IDs).
- Clean aligned ASCII tabular display.
- Search employee by ID.

### Schema
`emp_id, name, dept, salary`

### Files
- `employee_crud.py`: CLI and helper functions for CSV record management.
- `employee.csv`: CSV data store.
- `assignment2.ipynb`: Fully executed Jupyter notebook with all CRUD demonstrations.

### How to Run
```bash
python employee_crud.py
```
Or open `assignment2.ipynb` in VS Code or Jupyter Lab.
